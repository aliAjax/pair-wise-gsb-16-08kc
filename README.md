# 职业听力监护台

噪声岗位员工年度听力复测的听阈存档、标准听阈推移（STS）判定与 30 天复查随访工作台。

## 技术栈

React + Vite + TypeScript + CSS（无后端，数据保存在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 功能

- 按员工、左右耳、0.5 / 1 / 2 / 3 / 4 / 6 kHz 六个频点保存听阈（dB HL）
- **首次有效检查（基线）与年度复测分开留档**：新检查一律追加，任何新结果都不覆盖基线
- 复测以基线为对照自动判定标准听阈推移：
  - 单耳任一频点听阈提高 ≥ 15 dB
  - 单耳相邻两频点听阈平均提高 ≥ 10 dB
  - 命中即显示耳别、频点（或相邻频点对）与超出值，并自动开立待复测单
- 待复测可**登记预约复查日**，按开立日 + 30 天显示剩余天数 / 逾期；完成复查后保留原基线与复测曲线，复查曲线另档呈现
- 未完成复查前**不进入年度合格名单**
- 员工筛选（车间 / 状态 / 关键词）同步影响指标卡、待复测名单、合格名单与曲线详情
- SVG 听力曲线：左耳 ×、右耳 ○，基线虚线 / 复测实线 / 复查点划线，阈移频点橙色高亮
- 数据持久化到 localStorage，关闭浏览器再打开仍在；可一键恢复示例档案

## 代码结构（记录、判定、保存、页面分离）

```
src/audio/
  types.ts    记录类型：员工 / 检查（baseline | annual）/ 随访单 / 阈移命中
  rules.ts    判定层：STS 规则、PTA、命中描述（纯函数）
  records.ts  记录操作层：追加检查、开立/预约/完成随访、年度汇总（纯函数）
  storage.ts  保存层：localStorage 读写与旧档迁移
  seed.ts     示例档案（含阈移、无阈移、仅基线三类样例）
src/components/
  AudiogramChart.tsx    听力曲线（SVG）
  ThresholdInput.tsx    六频点左右耳阈值录入（带基线对照）
  ExamForm.tsx          新检查录入 + 保存前即时阈移预览
  FollowUpActions.tsx   预约登记、30 天期限标签、复查结果登记
  EmployeeDetail.tsx    员工详情：曲线、随访卡、检查留档
src/App.tsx             指标、筛选、名册、待复测与合格名单
```
